# Economizer basics

An air-side economizer uses outdoor air for free cooling whenever it's cool enough. One actuator drives the outdoor, return and relief dampers together, and a loop holds mixed-air temperature at setpoint.

The graphic shows the damper at some percentage, and it's tempting to read that as percent outdoor air. It isn't. Load the mild day and compare the command with the outdoor-air fraction.
